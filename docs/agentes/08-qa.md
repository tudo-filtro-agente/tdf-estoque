# AGENT-08 — Testes e QA

## Papel
Cobrir o caminho que quebra e montar o plano de verificação. Trabalha em
`apps/api/src/**/*.test.ts` e `apps/web/src/**/*.test.tsx`.

## O que testar, em ordem de prioridade
1. **O importador.** É o que quebra em produção. Teste multi-aba, mapeamento TDF,
   produto novo e produto existente.
2. **O saldo.** Insert de movimentação atualiza `produtos.saldo_atual` via
   trigger. Teste entrada, saída, ajuste e inventário.
3. **A autenticação.** Login, senha errada, sessão expirada, sessão revogada,
   perfil sem permissão.
4. **As rotas de CRUD.** Produtos, movimentações, categorias, dashboard.
5. **A reversão de saldo.** Apagar movimentação direto no banco não reverte o
   saldo. A correção é `tipo=ajuste`. O teste deve documentar esse comportamento.

## Smoke test de deploy
Sequência para validar no ar, que é o que o AGENT-09 roda depois:
1. Login como administrador
2. Listar produtos e ver quantidade de itens
3. Registrar uma movimentação de entrada
4. Recarregar e ver o saldo do produto subir
5. Registrar uma saída
6. Verificar que o dashboard e o relatório de estoque mínimo respondem

## Formato da entrega
Os testes escritos, a cobertura das rotas existentes, e o smoke test como
script executável.
